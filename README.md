# ✈️ UDAAN — Real-time Airfare Intelligence Portal

> **From Changing Airfare Data to Meaningful Intelligence**

UDAAN is a proposed real-time airfare intelligence platform that collects, standardizes and analyzes airfare observations from multiple sources to generate a representative **Airfare Price Index**.

Instead of looking at a single ticket price, UDAAN brings together multiple observations across airlines, routes, booking windows and travel sources to understand the broader movement of airfares.

## 💡 About UDAAN

Airfare is highly dynamic. The same route can have multiple valid prices depending on the airline, booking platform, travel date, advance-purchase window, availability and fare components.

This makes it difficult to represent the airfare situation using a single observed ticket price.

**UDAAN addresses this problem by converting multiple changing airfare observations into one standardized and representative Airfare Index.**

The platform creates a common analytical layer between raw airfare observations and meaningful aviation insights.

---

## 🎯 Problem Statement

Traditional airfare searches primarily answer:

> **“What is the price of a ticket right now?”**

UDAAN focuses on a broader question:

> **“How are airfares moving across routes, airlines and booking windows?”**

The objective is to transform scattered airfare observations into a structured and measurable indicator that can support analysis, monitoring and decision-making.

---

## ⚙️ How UDAAN Works

UDAAN follows a five-stage approach:

### 01. Automated Airfare Collection
Collects repeated airfare observations from airline portals and online travel sources across selected domestic routes.

### 02. Standardized Airfare Data
Converts different source formats into a common structure containing route, airline, travel date, booking window, fare components and total payable fare.

### 03. Data Quality & Continuity
Validates observations, removes duplicates, identifies abnormal values and handles missing or unavailable observations.

### 04. Statistical Index Engine
Transforms comparable airfare observations into an elementary price measure and aggregates route-level movements using the selected index methodology.

### 05. One Dataset, Multiple Uses
The same standardized dataset supports the UDAAN Index, fare trends, route analysis, booking-window analysis, forecasting and anomaly insights.

---

## 📊 UDAAN Airfare Index

The core of the platform is the **UDAAN Airfare Index**.

The index combines multiple airfare observations to provide a representative measure of airfare movement rather than relying on a single ticket price.

A defined base period is used to express changes in the measured airfare level over time.

This allows users to observe:

- Overall airfare movement
- Route-wise price changes
- Airline-wise variations
- Booking-window behaviour
- Historical trends
