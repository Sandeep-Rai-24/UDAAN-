How UDAAN Calculates the Airfare Price Index Statistical pipeline
Airfare Observations → Data Cleaning → Route & Airline Normalization → Outlier Detection → Weighted Average Fare → Route-Level Indices → National Aggregation → UDAAN Airfare Price Index
Base Period
2019 = 100
Current Index = Current weighted airfare / Base-period weighted airfare × 100
